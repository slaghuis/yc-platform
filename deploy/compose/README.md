# Compose Resources

Supporting files for the local Docker Compose dev stack.

- `postgres-init.sh` — creates one database per service on first Postgres start.
- `seaweedfs-s3.json` — S3 identities for SeaweedFS: `devkey` / `devsecret` with full access, and anonymous read on the `yc-images` bucket. Dev only.
- `dev-keys/` — generated by `scripts/gen-dev-jwt-keys.sh`. Gitignored. Dev only.

## Resetting

```bash
task devstack:reset
```

This wipes all Postgres data, NATS streams and S3 objects.

## Object storage

SeaweedFS (`weed mini`) provides the S3 API locally on port 9000, with its admin UI on port 9001. The `yc-images` bucket is created on startup. MinIO was used originally, but its container images are no longer published.
