# yc-platform

Multi-tenant e-commerce platform built as a Go microservices monorepo.

## Status

Scaffold. See `docs/implementation-plan.md` for the build sequence.

## Quick Start

```bash
# One-time setup
task bootstrap

# Start the local dev stack
task devstack:up

# Run tests
task test
```

See `docs/onboarding/` for setup details and `docs/README.md` for the full documentation map.
